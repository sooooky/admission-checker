# 🎓 입시 결과 조회 도우미

학생들의 수시·정시 원서 목록(엑셀)을 불러와 **대학별 합격자 조회 페이지로 바로 연결**하고, 조회 결과를 기록·엑셀로 내보내는 웹앱입니다.

## 개인정보 보호 원칙

- **서버가 없습니다.** 엑셀은 브라우저 안에서만 읽고, 학생 정보는 어디에도 업로드되지 않습니다.
- 배포본에는 콘텐츠 보안 정책(`connect-src 'none'`)이 적용되어 있어, 앱이 외부로 데이터를 보내는 것 자체가 차단됩니다.
- 학생 정보는 선생님이 정한 비밀번호로 **AES-256-GCM 암호화**(PBKDF2 60만 회)되어 그 PC의 브라우저에만 저장됩니다.
- 일정 시간 사용하지 않으면 자동으로 잠기고, 휴대폰 번호는 가려서 표시합니다.
- 대학 사이트에 자동으로 접속하지 않습니다. 선생님이 직접 조회 페이지를 열고, 입력만 도와줍니다.
- 이 저장소에는 학생 데이터가 없습니다. `.gitignore`가 엑셀·백업 파일의 커밋을 막습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 엑셀 불러오기 | 원서별 한 줄 / 학생별 한 줄(대학1…대학6) 형식 자동 인식, 열 직접 지정 가능, 앞자리 0 복원 |
| 조회 바로가기 | 대학별 조회 주소를 등록해 두면 [조회 ↗] 한 번에 새 탭으로 열림 (없으면 입학처 홈페이지) |
| 대학 정보 | 4년제 214개교의 입학처·2027 시행계획 링크 내장, 대학명만으로 자동 연결 (캠퍼스 선택, 줄임말 인식). 전문대는 직접 입력 |
| 발표 일정 | 대학별 발표·등록 일정 달력 + 전국 공통 일정 + **4년제 205개교 기본 일정(합격자·1단계·충원 발표, 면접·논술·실기)**, 날짜를 누르면 그날 조회할 원서 목록 |
| 복사 버튼 | 수험번호·이름·생년월일(6/8자리)·핸드폰 원클릭 복사 |
| 자동입력 북마크 | 대학 조회 페이지에서 북마크를 누르면 수험번호·이름·생년월일·핸드폰 칸을 채움 (조회 버튼은 직접) |
| 결과 기록 | 합격 / 충원합격 / 예비(번호) / 불합격 / 확인필요를 날짜와 함께 시간순으로 기록 (차수 구분 없이, 이전 번호 보존), 메모 |
| 예비 현황 | 예비번호를 받은 원서의 처음·최근 번호와 기록 경과, "오늘 미확인" 필터 |
| 등록·정시 | 최종 등록 대학(★) 표시, 모집 시기(수시/정시/추가)·정시 군 기록, 수시 합격자 정시 지원·군 중복 경고 |
| 오늘 할 일 | 오늘·내일 발표, 7일 내 마감, 등록 미정·경고·예비 대기·최저 확인 등 처리할 일 |
| 진학 실적 | 합격 학생 수·합격률·등록 확정, 수시/정시·4년제/그 외·대학별 현황 (엑셀 "진학 실적" 시트) |
| 내보내기 | 원서별 결과(경과 포함) + 학생별 요약 + 예비번호 변화 엑셀 (생년월일·핸드폰 포함 여부 선택) |
| 암호화 백업 | 다른 PC로 옮기거나 브라우저 기록 삭제에 대비 |
| 대학 정보 공유 | 조회 주소·링크·일정(개인정보 없음)을 파일로 동료와 공유 |

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 검사 + 배포용 빌드 (dist/)
```

`main` 브랜치에 올리면 GitHub Actions가 GitHub Pages로 자동 배포합니다. (저장소 Settings → Pages → Source: **GitHub Actions**)
